# Sistema de hábitos saludables

Sistema de escritorio desarrollado para apoyar la gestión, registro y seguimiento de hábitos saludables de los estudiantes del Instituto Nacional 21 de Junio, ubicado en Santo Tomás, Chontales.

El proyecto busca facilitar el registro y control de los hábitos saludables mediante una herramienta informática que permita organizar la información, consultar registros y generar estadísticas que apoyen la toma de decisiones.
